    Are you familiar with RL?

    Well, then you should be very familiar with classic DQN, and I’m pretty sure you don’t need any further explanation.

    In reinforcement learning, an agent learns by trial and error. At each step t it sees a state s_t, takes an action a_t, and gets back a reward r_t and the next state s_{t+1}. It is looking for a policy \pi(a \mid s) that maximizes the expected return, the discounted sum of future rewards:

    G_t = \sum_{k=0}^{\infty} \gamma^k\, r_{t+k}, \qquad 0 \le \gamma < 1.

    The action value Q^\pi(s, a) = \mathbb{E}_\pi[\, G_t \mid s_t = s,\ a_t = a \,] is the return you can expect after taking a in s and following \pi from then on. The best one, Q^*, satisfies the Bellman optimality equation

    Q^*(s, a) = \mathbb{E}\Big[\, r + \gamma \max_{a'} Q^*(s', a') \Bigm| s, a \Big],

    and once you know it, acting well is easy: take \arg\max_a Q^*(s, a).

    DQN approximates Q^* with a neural network Q_\theta. It keeps its transitions (s, a, r, s') in a replay buffer \mathcal{D} and trains on random batches from it, pulling Q_\theta toward a target y computed by an older copy of itself, Q_{\theta^-}:

    y = r + \gamma \max_{a'} Q_{\theta^-}(s', a'),
    \mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}} \big[ (y - Q_\theta(s, a))^2 \big].

    To keep exploring, it acts \varepsilon-greedily: a random action with probability \varepsilon, otherwise the action with the highest Q_\theta, and \varepsilon shrinks as it learns.
